# Stereo 與 Stereo IMU 分析報告

評估日期：2026-10-28。同一份錄製資料，各執行一次；先移動完成初始化，再返回原點開始路徑，最後回到原點。

**本次 Stereo-IMU 的起終點位置差較小、處理較快且沒有過載丟幀；Stereo 的角度差較小。**

## 關鍵數據

首尾差使用最終最佳化後的相機軌跡，取起始第 15–18 秒及結尾最後 3 秒的平均姿態。時間相對共同感測記錄起點。

| 指標 | Stereo | Stereo-IMU |
|---|---:|---:|
| 起終點位置差 | 96.52 cm¹ | **5.46 cm** |
| 起終點角度差 | **2.65°**¹ | 4.00° |
| 平均處理時間 | 27.83 ms | **21.19 ms** |
| 處理時間 P95 | 37.24 ms | **30.70 ms** |
| 排隊至處理完成平均時間 | 123.53 ms | **24.46 ms** |
| 過載丟棄影像對 | 41（0.13%） | **0** |
| 處理吞吐量² | 29.66 Hz | 29.81 Hz |

¹ Stereo 缺少程序結束紀錄，位置與角度差僅作診斷比較。

² 吞吐量以第一筆入列至最後一筆處理完成計算，不含節點啟動及完整關閉等待時間。

另以兩模式共同有效追蹤的 30,858 幀比較，Stereo-IMU 平均處理時間仍約少 **24%**。

## 白牆區段

操作者確認該區段為缺少特徵的白牆，沒有影像配對偏差。兩模式都中斷追蹤流程，建立新地圖後完成合併；Stereo 有 90 幀短暫失追，Stereo-IMU 則出現兩次重新初始化相關重置。**目前不能判定 Stereo-IMU 的白牆恢復能力較好。**

兩輪另有相同的 5.07 秒已處理影像間隔，其形成原因尚未確認，不能僅以白牆缺少特徵解釋。

## 輸入品質與限制

影像無重複或時間戳倒退。Stereo-IMU 的 IMU 平均間隔為 5.04 ms，無超過設定 20 ms 的間隔或緩衝區溢位。

本次僅一組比較，無真實軌跡參考；首尾差包含實際擺放誤差，不能代表全路徑絕對精度。Stereo 的完整性確認資料及兩輪軟體版本、設定識別資訊仍不完整，結果應作為後續重複測試的初步基線。
